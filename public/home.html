About the system

Why substitution management needs a system

Arranging cover for an absent faculty member is routine work that consumes a disproportionate amount of a department's time.

Manual substitution is time-consuming

Every absence means checking each period of the day and deciding cover for each one separately, usually at short notice.

Finding free faculty by hand is difficult

Knowing who is genuinely free at a given period means cross-reading every other faculty timetable at the same coordinate.

Timetable data is awkward to process

Timetables arrive as spreadsheets in different layouts, with merged lab periods and inconsistent labels for free slots.

TecSubstitution automates the lookup

It normalizes every timetable into one internal format and answers "who is free at this day and period" in a single click.

Features

What the system does

Each feature is implemented and covered by the automated test suite.

✓ Timetable Management

View any class timetable or an individual faculty member's own week, with period timings and rooms.

✓ Clickable Timetable

Every period is a control carrying its own day, period, class, subject, faculty and room.

✓ Faculty Availability Detection

One lookup returns everyone free at that exact coordinate, checked against all loaded timetables.

✓ Substitute Faculty Suggestions

Pick an absent faculty member and a day to see every period they teach and who could cover each one.

✓ Excel Timetable Import

Upload an .xlsx timetable; matrix and long-form layouts are both detected automatically.

✓ Timetable Validation

Invalid days, out-of-range periods, duplicate entries and double-bookings are reported, never silently accepted.

✓ Faculty Management

The full roster with teaching load — busy periods, free periods, subjects and classes per faculty.

✓ Automated Processing

Import, normalization and validation run as one pipeline, so every source produces identical internal data.

✓ Read-only Availability Checking

Checking availability never assigns a substitute or writes to any timetable. There is no write path in that code.

How faculty substitution works

Faculty X is unavailable for Monday P2

The system checks every other faculty member's schedule at that exact day and period.

  • ✓ Faculty A free
  • ✗ Faculty B teaching CN, CSE-B
  • ✓ Faculty C free
  • ✗ Faculty D teaching DBMS Lab

Result: Faculty A and Faculty C can be considered as substitutes. The list is displayed only — no substitution is assigned or saved.

Accepted columns

Day · Period · Class · Faculty · Subject · Room

A faculty-per-row matrix such as Faculty | Monday P1 | Monday P2 is also detected automatically. A cell reading FREE, “-”, or left blank means the faculty is not teaching then.

What validation catches

Unrecognised structures, invalid days and periods, duplicate entries for the same faculty and slot, a faculty double-booked across two classes, and empty timetables — each reported with the row it came from.
